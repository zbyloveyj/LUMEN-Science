# Acknowledgements and dependency notice

DAWN-Science was studied as an architectural reference for connecting AI conversations, R/Python kernels, project folders and result records. LUMEN's implementation in this repository was written independently; DAWN source files are not included.

Reference: https://github.com/Jiawang1209/DAWN-Science

Runtime dependencies include Jupyter Client/IPykernel, NumPy, Pandas, SciPy, Matplotlib, OpenPyXL and Paramiko. Optional dependencies include PyArrow, xlrd and Zig language distribution. Each dependency retains its own copyright and license; the MIT license on this repository applies to LUMEN's own code.

Downloaded dependency trees, compilers, local projects, credentials, runtime logs and databases are excluded from the Git repository and source archive.
