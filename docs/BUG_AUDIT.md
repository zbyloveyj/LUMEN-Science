# 0.2.0 执行检查记录

检查日期：2026-11-08。本记录区分实际运行、自动检查和未覆盖范围。

## 这轮发现并修复的问题

1. 打包后的程序不能被当作普通 Python 解释器使用。增加独立计算进程和明确的内核/脚本入口，避免重复打开程序或传参失败。
2. 内核启动需要动态加载调试器的附带源码。补齐该依赖，修复“页面可以打开但持续计算无法启动”。
3. 保存内置环境的路径时，需要继续使用内置进程的启动协议。已增加识别和回归检查；安装版设置页留空即可使用内置 Python。
4. 增量打包可能保留构建期间修改前的模块。发布构建强制清理缓存，随后在不含系统 Python 的 PATH 下验收。
5. 发布机下载构建工具可能收到 HTML 页面。改为多个官方镜像重试，并要求固定 SHA-256 匹配后才解压；微软组件同时检查数字签名。
