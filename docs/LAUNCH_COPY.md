# 开源预览推广材料

状态：开源预览介绍稿。以下文案未发布到社交或内容平台。

## 项目简介

LUMEN Science 是一个开源、本地优先的 AI 科研工作台，把项目文件、多语言计算、AI 协作、文献和结果记录连接起来。它支持 Python、R、C/C++、Java 等十二种语言的执行适配，并提供 SSH/SFTP 服务器连接。当前为0.1.0早期预览，欢迎用合成或可公开的数据试用并反馈。

## 一段话介绍

做研究时，数据、代码、AI 对话和结果经常散在不同窗口。LUMEN Science 希望让这些工作围绕同一个项目接续：查看数据、运行不同语言的代码、连接服务器、查询文献，再把实际运行和成果整理为可交接的记录。它目前已经提供多语言执行、四个分析流程、结果留存和独立重跑。项目仍处于早期，欢迎大家提出可复现的问题，一起把常用科研流程做扎实。

仓库链接：https://github.com/zbyloveyj/LUMEN-Science

## 建议演示顺序（约90秒）

1. 打开合成示例项目，说明没有使用真实受试者或私有数据。
2. 展示数据结构和缺失质量概览。
3. 在 Notebook 中运行 Python，再展示 C/C++ 或 Java 的编译及输出。
4. 执行数据质量流程，展示实际图表和结果表。
5. 展开运行来源，展示输入指纹、代码和结果快照。
6. 展示 SSH 连接页面；没有真实验收服务器时只介绍入口，不假装已经连接。
7. 导出项目交付包，说明当前版本的已知限制。

## 对外表达边界

可以说：提供十二种语言适配、真实本地执行、主机指纹固定的 SSH/SFTP、结果版本与独立运行检查。

不要说：支持所有语言而无需安装环境、保证科研正确、完整自动复现、已经通过全平台验收、全面超过某个竞品、已完成真实服务器和全部模型服务商验收。

## 发布前准备

- 使用上述真实仓库链接，通过 Issues 和 Pull Request 接收反馈与贡献。
- 放置实际运行截图或录屏；无法获取时不要用概念图冒充截图。
- 明确预览版、安装条件、测试范围和已知限制。
- 初期推广面向愿意提供可复现反馈的研究者和开发者。
- 按真实反馈改进稳定性，再扩大宣传范围。
